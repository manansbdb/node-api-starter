# Node API Starter / Starter de API Node

## Overview / Visão geral

**EN:** Minimal Express-style folder scaffold for a Node.js HTTP API. Scaffold only — no `npm install` required to browse the layout.

**PT:** Estrutura mínima estilo Express para uma API HTTP em Node.js. Apenas scaffold — não é necessário `npm install` para explorar a estrutura.

## Structure / Estrutura

```
src/
  index.js          # entrypoint
  app.js            # app factory
  routes/health.js  # sample route
package.json        # scripts & deps (example)
```

## Getting started / Começar

**EN:** Copy this tree into a new project, run `npm install`, then `npm start`.

**PT:** Copia esta árvore para um projeto novo, corre `npm install` e depois `npm start`.
