## Install / Instalação

### 1) Clone

```bash
git clone https://github.com/manansbdb/node-api-starter.git
cd node-api-starter
```

### Use / Usar

```bash
src/
  index.js          # entrypoint
  app.js            # app factory
  routes/health.js  # sample route
package.json        # scripts & deps (example)
```

### Requirements / Requisitos

- `git`
